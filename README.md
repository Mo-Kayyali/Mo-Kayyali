## 🚀 Featured Projects

### 🤖 [AINAI](https://github.com/AinaiGP) — AI-Powered Fashion E-Commerce Platform
> **Graduation Project · Backend Architecture Lead**

An end-to-end AI-integrated e-commerce platform for fashion. Built for real production load with event-driven patterns, multi-modal AI features, and a modular monolithic backend.

**What it does:**
- 🪄 **Virtual Try-On** — Users upload a photo and try on clothing items via a FastAPI AI model, proxied through NestJS
- 💬 **AI Shopping Assistant** — Gemini-powered floating chatbot with product-aware context
- 🛒 **Smart Cart & Inventory** — Redis-backed cart merging, real-time inventory reservation, and atomic stock management
- 🔍 **Fuzzy Product Search** — PostgreSQL `pg_trgm` full-text search with filtering and pagination
- 🔐 **Auth System** — JWT + Google OAuth, RBAC, refresh token rotation

**Stack:** `NestJS` · `PostgreSQL` · `Redis` · `AWS SQS` · `Docker` · `Cloudinary` · `Google Gemini` · `FastAPI`

### ⚽ [El La3eba](https://github.com/Mo-Kayyali/El-La3eba-Showcase) — Competitive Football Trivia Platform
> **Personal Project · In Development · Full Stack**

A real-time competitive online gaming platform built around football knowledge. Players challenge each other in live 1v1 lobbies and climb global leaderboards.

**How it works:**
- 🏟 **1v1 Live Lobbies** — Real-time best-of-3 challenge format; first to 3 strikes loses the point
- 🌐 **Multiplayer Online** — Join via invite code or challenge a friend live
- 🏆 **Leaderboard & Point System** — Global rankings with a persistent scoring engine
- 👥 **Friends System** — Add friends, see their status, and invite them directly to a lobby
- 🤖 **AI Integration** — Coming soon: AI-powered question generation and difficulty balancing
- 🎮 **More Game Modes** — Expanding beyond 1v1 with new formats on the roadmap

**Stack:** `NestJS` · `PostgreSQL` · `TypeScript` · `Docker` · `WebSockets`
